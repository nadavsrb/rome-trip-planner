# רומא שלנו · 12–17.11.2026

אפליקציית ווב לטלפון לתכנון הטיול שלנו לרומא. היא עובדת מתוך הדפדפן, אפשר להוסיף אותה למסך הבית, והיא עובדת גם בלי אינטרנט.

**מה יש בה**
- **לו״ז**: ציר זמן לכל יום עם זמני הליכה, מזג אוויר, שקיעה ואזהרות על ימים או שעות שבהם מקום סגור. אפשר לגרור, להוסיף ולהעביר פעילויות בין ימים, ולבנות לו״ז מוצע לפי קצב (רגוע / מאוזן / אינטנסיבי) ותחומי עניין.
- **לגלות**: אטרקציות, מוזיאונים, חוויות, שופינג, אירועים בתאריכים שלנו וטיולי יום, עם סינון (גשם, חינם, פתוח ביום מסוים, אזור).
- **אוכל**: מסעדות כשרות קודם, ומקומות טובים לצמחונים. כולל מדריך כשרות ושבת ומדריך לצמחונים.
- **מלון**: השוואת שכונות ומלונות לפי מחיר, דירוג, תכונות ומרחק מהלו״ז שלנו, עם קישור ל-Booking שהתאריכים כבר ממולאים בו.
- **מפה**: תחנות הלו״ז לפי ימים, או כל המקומות.
- **מידע**: צ׳קליסט לפני הטיסה, הגעה מהשדה, תחבורה, כסף, ביטחון, טלפונים לחירום ומשפטים באיטלקית.

**שיתוף בין הטלפונים**: כל טלפון שומר את התוכנית אצלו. הכפתור "שיתוף" שולח קישור עם התוכנית לטלפון השני.

## פיתוח

- אין build. HTML, CSS ו-JavaScript (ES modules) נטענים ישירות.
- הנתונים נמצאים ב-`data/*.json`. כדי לעדכן תוכן מספיק לערוך אותם, והאתר מושך אותם מהרשת לפני המטמון.
- כשמשנים קבצי קוד, מעלים את `VERSION` ב-`sw.js` כדי שהטלפונים יקבלו את הגרסה החדשה.
- שרת מקומי: `python tools/serve.py 5180`, ואז לפתוח את http://localhost:5180 (ה-service worker כבוי ב-localhost אלא אם מוסיפים `?sw=1`).
- אייקונים: `node tools/make-icons.mjs`.

שעות ומחירים נאספו בנובמבר 2026 ועלולים להשתנות. לפני ביקור כדאי לבדוק באתר הרשמי.
