# רומא שלנו · 12–17.11.2026

אפליקציית ווב לטלפון לטיול שלנו לרומא. היא עובדת מתוך הדפדפן, אפשר להוסיף אותה למסך הבית, והיא עובדת גם בלי אינטרנט.

**מה יש בה**
- **לו״ז**: הלו״ז הסופי שלנו, יום אחרי יום, עם זמני הליכה ונסיעה, שקיעה ואזהרות כשמקום סגור או כשלא מספיקים להגיע. כרטיס "עכשיו / הבא" עם כפתור ניווט, משבצות עם שתי אופציות (לוחצים כדי לבחור), סימון "עשינו", עריכה (שעה, משך, הערה, אופציות, העברה בין ימים, הוספה עם שעה) ושחזור ללו״ז המקורי. לכל יום יש כפתור שפותח את המסלול המלא ב-Google Maps.
- **מפה**: כל מקום עם סמל לפי הסוג (🍝 מסעדה, 🍕 פיצה, 🍦 גלידה, ☕ קפה ומאפייה, 🏛️ אתר, ⛲ כיכר ועוד), מסגרת בצבע היום שבו מבקרים בו, ומספר לפי הסדר באותו יום. אפור מקווקו = ברשימה אבל עוד לא שובץ. יש מקרא.
- **לגלות / אוכל**: כל המקומות מהמפה שלנו (גם אלה שעוד לא שובצו) תחת "📍 שלנו", לצד שאר האטרקציות והמסעדות.
- **מלון**: Dimora Frattina, עם ניווט, כתובת להראות לנהג, זמני הליכה ויציאות וחזרות לפי הלו״ז.
- **מידע**: צ׳קליסט, הגעה מהשדה, תחבורה, כסף, טלפונים לחירום ומשפטים באיטלקית.

**סנכרון בין הטלפונים**: דרך Firebase Realtime Database (חינמי, בלי שרת). מפעילים פעם אחת בהגדרות, שולחים קישור לטלפון השני, ומאז כל שינוי עובר אוטומטית. בלי אינטרנט השינויים נשמרים ונשלחים כשהחיבור חוזר. בלי סנכרון אפשר עדיין לשלוח קישור חד-פעמי עם התוכנית.

## פיתוח

- אין build. HTML, CSS ו-JavaScript (ES modules) נטענים ישירות.
- הנתונים ב-`data/*.json`:
  - `schedule.json`: הלו״ז הסופי (ממנו נבנית התוכנית בפעם הראשונה, ואליו חוזרים ב"שחזור").
  - `ours.json`: המקומות מהמפה שלנו (משובצים ורשימת משאלות), ותיקונים קטנים למקומות מהמאגר.
  - `places.json`, `food.json`, `hotels.json` ועוד: המאגר הכללי.
- כשמשנים קבצי קוד, מעלים את `VERSION` ב-`sw.js` כדי שהטלפונים יקבלו את הגרסה החדשה.
- שרת מקומי: `python tools/serve.py 5180`, ואז לפתוח את http://localhost:5180 (ה-service worker כבוי ב-localhost אלא אם מוסיפים `?sw=1`). כשהאפליקציה רצה ב-localhost, הסנכרון מקבל גם כתובת `http://127.0.0.1:<port>` של אמולטור.
- אייקונים: `node tools/make-icons.mjs`.

שעות ומחירים נאספו בנובמבר 2026 ועלולים להשתנות. מקומות שהשעות שלהם לא אומתו מסומנים ככה בפרטים.
